01Same process, different machine, fewer sensors

A CNC world model should predict what the process does next under a candidate action, and it should keep working when it is moved to another machine whose sensing interface is not the one it was trained on.

We train on the THWS Spinner U5-620 five-axis machining centre — 17 canonical sensor channels, 62 NC-program sessions on a 1 Hz grid — and transfer to the FH JOANNEUM repository, where only 10 of those channels exist across 7 independent runs. Actions are the spindle speed and the commanded X/Y/Z feeds. The model takes a K = 32 s context and predicts directly at horizons {1, 2, 4, 8, 16} s rather than rolling out autoregressively.

The headline is deliberately narrow and partly negative. JEPA pretraining does not improve clean-source forecasting over matched scratch training. What it buys is a controllable, uncertainty-aware latent that survives a 17-to-10 schema drop on a machine it has never seen — measured once, after the configuration was locked on source data alone.

02The architecture

03What a world model buys you

A forecaster answers “what happens next”. A world model answers “what happens next if I do this”. On highly autocorrelated industrial streams the two are easy to confuse: a model can score well at short horizons while effectively ignoring the control input.

04The lock: how the target machine was kept out

Twenty candidate architectures were written down before any of them ran. Ranking used a composite source-validation score — 0.30 clean RMSE, 0.25 schema-drop RMSE, 0.15 masked RMSE, 0.10 long-horizon RMSE, 0.10 calibration, 0.10 SSL validation loss, plus penalties of 3.0 per collapsed seed and 1.0 for weak action usage. When the provisional winner changed under confirmation, locking was refused and more seeds were added.

06A little target data goes a long way

07What this does not show

Read the limitations before citing a number.

  • One source machine and one target machine. Nothing here measures invariance to machine-specific dynamics; it assumes it. Seven independent JOANNEUM runs also restrict statistical power, and seven source channels have no target counterpart at all.
  • The confirmatory target result is a single checkpoint, evaluated once. It is the best-composite seed of seven source-validation seeds, so the target number is single-seed. Run-level confidence intervals on the locked model have not been computed.
  • The few-shot curve is pre-lock. It was obtained before the model was frozen and must be re-measured on the locked configuration before it counts as confirmatory evidence.
  • Action use under transfer is unverified. On the pre-lock model, zeroing or shuffling the future actions changed target RMSE by less than 0.005. That is the first thing to test. The same model was also under-calibrated: 67 % empirical coverage at a nominal 90 %.
  • Ablations are single-seed on the pre-search base configuration, and the official baselines are single-seed runs at repository defaults without hyperparameter search.
  • No downstream policy learning or off-policy control is evaluated, so the world-model interpretation stays predictive rather than decision-theoretic.
